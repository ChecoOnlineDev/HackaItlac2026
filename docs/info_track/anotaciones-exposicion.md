# Anotaciones personales de la exposición

Este archivo contiene las notas compartidas por el participante sobre la exposición. Son apuntes personales y no una transcripción literal del PDF de 10 páginas. Se conservan por separado para distinguirlos de los requisitos y materiales mostrados en el documento.

## Operación y personas

- Se necesita una aplicación sencilla e intuitiva. Actualmente hay un almacén sin control de herramientas.
- El trabajador primero acude a Recursos Humanos (RH), donde recibe un contrato.
- Dar de alta a los trabajadores en el sistema.
- Escanear un código para recuperar los datos del trabajador y generar un vale de resguardo foliado.
- Caso de prueba: una persona es contratada, se da de alta en el sistema y acude al almacén general de Kepler a solicitar equipo básico de protección personal, por ejemplo lentes, guantes, calzado, protección auditiva y respiratoria.
- Mantener historial de quién tiene cada equipo en todo momento y conocer adeudos.
- Cada herramienta debe tener número de serie. Las herramientas de mayor valor necesitan un control más estricto.
- Hay almacenes asociados específicamente a cada trabajador y un almacén central donde se entrega un equipo base.
- Las herramientas no se entregan diariamente; se necesita conocer quién tiene cada una en cada momento.
- Al devolver el equipo, se maneja un vale de no adeudo.
- También puede solicitarse equipo de altura y generar una petición.
- Poder identificar adeudos de una persona incluso si vuelve a ser contratada.
- El almacenista debe poder consultar lo que debe cada persona.
- Considerar el periodo del proyecto o del contrato.

## Inventario, movimientos y compras

- Se requiere inventario de herramientas.
- Registrar firma digital al sacar herramientas, descontar existencias y generar un vale digital que el trabajador firme al sacar herramienta pequeña.
- Para consumibles, manejar una red de almacenes de ida y regreso con el mismo flujo y conservar el historial de consumos.
- Cuando no se tiene una herramienta necesaria para ejecutar el trabajo, generar una solicitud de compra para el proyecto (“CASO ESPECI M”, frase anotada tal como fue dictada).
- Para herramientas caras, manejar estados de la herramienta, quizá con códigos de daño o estados.
- Definir un tope mínimo de equipos por almacén y generar alertas inteligentes.

## Tecnología y captura

- Considerar pistola lectora USB/Bluetooth y celular/cámara/pistola.
- Solución propuesta durante la exposición: PWA.
- La aplicación debe poder configurarse por equipo.
- Usar como identificador el número/ID que les asigna la planta.
- El Internet falla con frecuencia; se requiere sincronización.
